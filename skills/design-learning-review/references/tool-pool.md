# 按需能力池

先指出不确定性，再选择能解决它的最小工具组合。现有材料足够时可不调用工具；发现新缺口才增补。没有新信息就停止。以下是能力参考，不是安装清单；使用前检查当前可用性和权限，不自动安装插件、不自动写配置或项目文档、不向外部发送真实项目资料。

| 能力 | 有价值的用途 | 不能据此证明 |
|---|---|---|
| 项目基准/现状只读检查 | 入口、规则、能力保留与实际变更对照 | 未读区域没有相关功能 |
| 截图/原型/运行界面 | 可见层级、关系表达、具体状态走查 | 单截图证明全状态、可访问性或数据安全 |
| design-critique | 对已有稿提供可用性、层级、一致性反馈 | 自动独立审查或业务正确性 |
| 浏览器测量/可访问性检查 | 对比度、焦点、溢出等具体疑问 | 自动测量覆盖全部可用性 |
| 用户证据/任务测试 | 验证可发现性、理解和完成成本 | 少量样本代表全部用户 |
| 独立审查者 | 从原始任务独立识别遗漏 | 同模型角色扮演等于独立验证 |

## 已接入、参考与条件启用

上游核对日期：2026-10-29；未来升级先核对差异，不静默更新。
- **已接入只读专业指导**：同级个人 Skill `impeccable-review`，直接读取其 SKILL.md。需要深入评审层级、认知负担、反馈恢复或技术证据时，优先按其相关检查补充；简单任务不加载。它是 [Impeccable](https://github.com/pbakaus/impeccable) 的裁剪改编，不是完整官方安装；没有检测器、浏览器脚本或钩子。固定来源与差异见该 Skill 的 references/source.md。不得声称官方 critique/audit 全流程或检测器已运行。不存在时如实说明，不自动安装。
- **保留参考、不单独安装**：[Anthropic frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design)，视觉方向与已有能力部分重叠；构建指导不构成代码授权，不用于证明任务关系正确。
- **特定缺口再评估**：[UI/UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)，已核对上游提供检索和设计系统生成，但未安装运行；缺少视觉基准、需探索风格时才比较实际增量，不作为默认依赖。
- **有设计源时连接**：[Figma](https://developers.figma.com/docs/figma-mcp-server/)，真实设计基准位于 Figma 且获授权时，读取组件、变量、布局才有明确价值。本版未连接，不声称已读取文件。Product Design 也不作为默认依赖。
- 本机 stitch-loop 在本版检查时仅为目录介绍，不是完整可运行工作流。Refactoring UI 为可选学习资料，本版未核验具体内容，不作为已验证规则来源。

多个视觉生成器输出相似稿不能证明操作顺序正确；可改用当前入口材料与任务走查提供不同证据。对争议所需证据不可得时，报告限制而非重复生成直到获得想要的答案。

资料级专业指导能扩展视角，但同一模型读两套指导仍是自查；只有实际测量、操作、不同原始材料或独立审查带来的新增信息才能补充证据。报告实际加载/运行能力及增量，允许结果为“未增加发现”，不凑工具或问题数量。
