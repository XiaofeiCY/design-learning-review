# 验证记录

## 已有验证

初版和优化版在个人目录通过 skill-creator 官方 quick_validate（UTF-8 模式），本地引用、元数据与安装文件一致性核对通过。

两位不继承主对话的子代理分别使用旧版和优化版，在相同合成材料上执行只读评审，未读取对方结果。双方都识别可选模板被编号成前置步骤、入口承接待核对、主次与任务不符、异步反馈、错误恢复、覆盖规则未知、源码键盘/裁切风险，并接受独立的间距调整后停止。

双方均实际计算普通文字 #777777 在 #FFFFFF 上对比度约 4.478:1，未虚构浏览器或检测器运行。优化版更显式区分证据边界及范围外要求，但没有独有关键问题发现；同模型的一次合成对照不是准确率、因果或长期效果证明。

合成输入见 [review-fixture.md](../tests/fixtures/review-fixture.md)，历史交付保存更完整的背景与限制。

## 迁移结构检查

运行 `python -X utf8 tests/validate_structure.py`。它检查 Skill 必要文件、目录命名、Markdown 本地引用，以及只读适配不携带可执行脚本。安装副本的一致性单独比较，不自动覆盖。

结构检查不证明评审正确；改动实际判断逻辑后应按受影响风险重新验证。真实项目反馈尚待用户试用。
